Dumps Active Directory Integrated DNS over LDAP via the Direct Sockets API. For authorised security testing only.

Target

Credentials

Scope

Idle.
TCPSocket has no TLS, so this is LDAP/389. NTLMv2 does not send the password, but the bind is unsigned/unsealed — it fails against DCs that require LDAP channel binding. Kerberos needs the DC host to be the FQDN matching its ldap/ SPN, the realm set, and the clock within ~5 min of the DC (the client auto-corrects from the KDC's time). Simple bind sends the password in cleartext. Authorised testing only.
